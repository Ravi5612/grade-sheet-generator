# Grade Sheet PDF Generator

Ye Python script I.K. Gujral Punjab Technical University (PTU) ki Grade Sheet PDF generate karta hai.

## Features
- Original marksheet jaisi exact design
- PTU logo embedded
- Real QR code generate hota hai
- Signatures included
- Ek click mein PDF generate

## Requirements
```bash
pip install qrcode pillow
```

## Usage
```bash
python generate_pdf.py
```

PDF file `Final_Grade_Sheet_v2.pdf` ke naam se save hogi.

## Output
Script run karne par ye PDF generate karegi:
- Student details (Name, Father's Name, Roll No)
- Grade table with all subjects
- SGPA
- Signatures
